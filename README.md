# Hot Wheels × Детский мир × Ашан — Telegram-бот

Бот следит за наличием Hot Wheels (по штрихкоду) в магазинах «Детского мира» и Ашана в Москве и присылает уведомления о поставках.

## Ашан: точные остатки

API приложения «Мой АШАН» отдаёт **точное количество** по каждому магазину (даже там, где само приложение число не показывает). Бот проверяет все магазины Ашана в Москве (кроме исключённых в `AUCHAN_EXCLUDE`, по умолчанию «Европарк») и присылает:

- 🆕 **Новый кейс!** — остаток вырос сразу на `CASE_THRESHOLD`+ штук (по умолчанию 50);
- 📈 **Остаток вырос** — любой рост (порог — `AUCHAN_MIN_INCREASE`, по умолчанию 1), в том числе с нуля;
- 🕳 **Закончился** — тихо.

Это остаток по учёту магазина: он может отличаться от того, что лежит на полке (товар ещё не выложен, уже разобран, но не списан и т. п.). Проверка Ашана идёт по одному запросу на магазин с паузой 1–3 с — около 1,5 минуты на товар.

## «Детский мир»: только уровни

Сайт и приложение «Детского мира» **не показывают точное количество** товара в магазине. По каждому магазину доступен только уровень:

| Уровень на сайте | В боте |
|---|---|
| товара нет (на сайте — только самовывоз под заказ) | нет в наличии |
| `LAST` | последние штуки |
| `LOW` | мало |
| `MEDIUM` | средне |
| `HIGH` | много |

Уровень «много» начинается с небольших значений: магазин, где по сканеру 60 штук, и магазин, где 630, выглядят одинаково. Поэтому:

- **бот автоматически ловит** поставки туда, где товара не было или было мало (нет → есть, последние → мало → средне → много);
- **приход нового кейса в магазин, где ещё много товара, автоматически не виден.** Для этого есть ручной журнал `/log`: в магазине сканируете машинку и записываете число, а бот считает прирост и отмечает новый кейс (по умолчанию от +50).

### Дата самовывоза («ближайшие поставки»)

Для магазинов, где товара нет, сайт и приложение показывают дату самовывоза под заказ: «завтра», «чт 30.10» и т. п. Это день, когда заказ, оформленный сейчас, приедет в магазин со склада. Бот показывает эти даты в `/soon` и `/status`. Это **ориентир**, когда в магазин поедет машина со склада, но **не гарантия**, что на полку выложат новый кейс.

## Команды

| Команда | Что делает |
|---|---|
| `/add 0074299057854` | добавить товар по штрихкоду — ищется в обеих сетях |
| `/remove 0074299057854` | удалить товар |
| `/list` | отслеживаемые товары |
| `/soon [штрихкод]` | «Детский мир»: **ближайшие поставки** — магазины без товара по дате самовывоза (⭐ — ваши выбранные) |
| `/status [штрихкод]` | Ашан — количество по магазинам; «Детский мир» — где нет или мало (с датой самовывоза) |
| `/stores` | режим уведомлений: все магазины Москвы / только выбранные |
| `/stores гагаринский` | найти магазин (по названию, улице, метро или коду) и отметить кнопкой |
| `/history 0074299057854` | история поставок по магазинам (автоматические и из ручного журнала) |
| `/log гагаринский 630` | записать точный остаток со сканера; при нескольких товарах добавьте штрихкод: `/log 157 630 0074299057854` |
| `/check` | проверить прямо сейчас |

Бот отвечает только на ваш `ADMIN_CHAT_ID`, сообщения от остальных игнорирует.

### Какие уведомления приходят

- 🚚 **Поставка** — товар появился в магазине, где его не было, или вырос уровень. В сообщении: товар, магазин, адрес, метро, было → стало, когда можно забрать, время проверки.
- 🛻 **Везут под заказ** — в магазине товара нет и раньше его туда даже не везли, а теперь появилась дата самовывоза. (Обычный ежедневный сдвиг даты уведомлением не считается.)
- 🕳 **Закончился** — товар пропал из магазина (тихое уведомление; отключается через `NOTIFY_SOLD_OUT=false`).
- ⚠️ **Проверка не удалась** — сайт не ответил или поменял формат ответа. Сообщение приходит один раз, а когда всё восстановится — «✅ снова проходят». Бот при этом не падает.

Самая первая проверка нового товара — базовая, уведомлений по ней нет.

## 1. Создать бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`.
2. Придумайте имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456789:AAH...` — это `BOT_TOKEN`. Никому его не показывайте.
4. Откройте своего бота и нажмите **Start** — иначе бот не сможет вам написать.

## 2. Узнать свой chat_id

Самый простой способ — написать [@userinfobot](https://t.me/userinfobot): он ответит вашим `Id`. Это и есть `ADMIN_CHAT_ID`.

Другой способ: напишите что-нибудь своему боту и откройте в браузере
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` — значение `"chat":{"id": ...}`.

## 3. Настройки

```bash
cp .env.example .env
nano .env   # впишите BOT_TOKEN и ADMIN_CHAT_ID
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | токен от BotFather |
| `ADMIN_CHAT_ID` | — | ваш chat_id |
| `CHECK_INTERVAL_MIN` / `MAX` | 20 / 30 | интервал проверки, минуты (берётся случайный между ними) |
| `REGION_ISO` | `RU-MOW` | регион API (отдаёт Москву и часть области) |
| `CITY_PREFIX` | `Москва` | учитывать только магазины, чей адрес начинается с этого (пусто — весь регион) |
| `CASE_THRESHOLD` | 50 | прирост (в Ашане и в `/log`), который считается новым кейсом |
| `AUCHAN_ENABLED` | true | проверять Ашан |
| `AUCHAN_EXCLUDE` | `009` | коды магазинов Ашана, которые не проверять (через запятую) |
| `AUCHAN_MIN_INCREASE` | 1 | с какого прироста в Ашане присылать уведомление |
| `NOTIFY_SOLD_OUT` | true | уведомлять, что товар закончился |
| `RECENT_HOURS` | 24 | сколько часов `/check` и `/status` показывают последние поставки (0 — не показывать) |
| `DB_PATH` | `data/hotwheels.db` | файл базы SQLite |

## 4. Запуск локально

Нужен Python 3.11+.

```bash
cd hotwheels-bot
python3 -m venv .venv
source .venv/bin/activate        # fish: source .venv/bin/activate.fish
pip install -r requirements.txt
python -m app.main
```

Затем в Telegram: `/add 0074299057854`, `/add 0027084120134`, `/status`.

Тесты: `pip install -r requirements-dev.txt && pytest -q`.

## 5. Запуск на VPS

Подойдёт любой VPS с 512 МБ памяти. **Лучше российский**: сайт «Детского мира» может ограничивать запросы с зарубежных адресов. Проверить с сервера:

```bash
curl -s -o /dev/null -w "%{http_code}\n" "https://api.detmir.ru/v4/products/143502/delivery/offline?filter=region.iso:RU-MOW"
# должно быть 200
```

### Вариант А: Docker (проще)

```bash
# установить Docker: https://docs.docker.com/engine/install/
git clone <ваш репозиторий> hotwheels-bot   # или скопируйте папку через scp
cd hotwheels-bot
cp .env.example .env && nano .env
docker compose up -d --build
docker compose logs -f          # смотреть логи, выход — Ctrl+C
```

Обновить код: `docker compose up -d --build`. Остановить: `docker compose down` (база сохранится в томе `botdata`).

> Если сборка падает с `Network is unreachable` на шаге `pip install` — у Docker нет доступа в сеть. Добавьте в `docker-compose.yml` в секцию `build` параметр `network: host`:
> ```yaml
>     build:
>       context: .
>       network: host
> ```

### Вариант Б: systemd

```bash
sudo useradd -r -m -d /opt/hotwheels-bot hotwheels
# из папки проекта (без локальных .venv, .env и базы):
sudo rsync -a --exclude .venv --exclude .env --exclude data ./ /opt/hotwheels-bot/
sudo chown -R hotwheels: /opt/hotwheels-bot
cd /opt/hotwheels-bot
sudo -u hotwheels python3 -m venv .venv
sudo -u hotwheels .venv/bin/pip install -r requirements.txt
sudo -u hotwheels cp .env.example .env && sudo -u hotwheels nano .env

sudo cp deploy/hotwheels-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now hotwheels-bot
journalctl -u hotwheels-bot -f   # логи
```

## Как это устроено

- `app/detmir.py` — клиент сайта: не больше одного запроса одновременно, пауза 1–3 с между запросами, до 4 повторов с экспоненциальной задержкой при ошибках сети, 429 и 5xx, браузерные заголовки. Используются те же открытые запросы, что делает сайт:
  - `GET https://api.detmir.ru/v4/products?search=<штрихкод>` — найти товар;
  - `GET https://api.detmir.ru/v4/products/<id>/delivery?filter=region.iso:RU-MOW` — наличие и дата самовывоза сразу во всех магазинах региона (один запрос на товар, ~300 КБ в сжатом виде).
- `app/auchan.py` — клиент API приложения «Мой АШАН» (`mobile.auchan.ru`; сайт auchan.ru закрыт антибот-защитой, её бот не обходит):
  - `GET /api/stores` — список магазинов (обновляется раз в сутки);
  - `POST /ecom/catalog/product-by-ean` — найти товар по штрихкоду;
  - `GET /ecom/catalog/product-detail?gima_id=…&merchantId=…` — остаток в магазине (`stock.qty`).
- `app/http.py` — общий «вежливый» HTTP-клиент (очередь, паузы, повторы).
- `app/monitor.py` — сравнение с прошлой проверкой и поиск событий.
- `app/db.py` — SQLite: товары, магазины, текущие уровни, история изменений, журнал проверок, ручной журнал.
- `app/bot.py` — команды и уведомления (aiogram 3).

Если сайт изменит формат ответа, бот пришлёт сообщение «⚠️ формат ответа изменился» — тогда нужно поправить `parse_stock` в `app/detmir.py`.
